# METIS-LIS

## Purpose

LIS METadata Information System resources including variable codebooks, indicator definitions, and wave/date documentation. These files provide essential reference information for working with LIS microdata.

## Quick Start

View the LIS codebook:
```bash
# PDF version
open METIS-LIS/codebook.pdf

# MIMA indicator definition
cat METIS-LIS/mima_indicator.md
```

Check wave dates and dataset availability:
```bash
cat METIS-LIS/waves-and-dates.md
```

## Contents

- `codebook.pdf` — Comprehensive LIS variable codebook with definitions and codes
- `mima_indicator.md` — Median Income Moving Average indicator definition and methodology
- `waves-and-dates.md` — LIS data waves and reference dates for all countries

## Conventions

- Files in this folder are reference materials from LIS
- Do not modify without consulting LIS documentation updates
- Link to online METIS when programmatic access is needed: https://www.lisdatacenter.org/frontend
